## Public API

Protocol and manifest schema remain 1; edition remains 2021 and MSRV 1.88.
Feature defaults are empty. `install`, `watch`, `engines` each work alone;
`trayhost` includes `watch`. Existing public `Manifest`, `ManifestSettings`,
`Locations`, `ServerConfig`, `ErrorCode` and Handler implementations keep
compiling unchanged. No existing fields were added to those struct literals.

- `accelerator`: `normalize`, `is_canonical`, `display(…, Platform)` and
  `conflicts`, with `AcceleratorError`. Sequences, ordered modifiers, taps,
  punctuation, XKB/keypad/Hyprland aliases, MicMute and horizontal wheel keys.
- `shortcuts`: `Document`, `Sheet`, `Group`, `Shortcut`, `ValidationError`.
  from_json/validate/markdown, effective OS bindings, case-insensitive sheet
  matching, unique IDs, context/OS sequence-prefix conflicts, optional manifest
  validation for rebindable globals. Python uses the same shared vectors.
- `receipt`: `Receipt`, `Integration`, `Previous`, `InstallMethod`, `ManagedBy`,
  `Store::new(&Locations)`/discover/read/write/remove. Atomic validated private
  receipts live beside the registry, honoring ARCADE_HOME. Dev writes are refused.
- `manifest`: `ManifestDocument {manifest, additions}` and `ManifestAdditions`
  add menu/logs/docs/install plus settings.trayHost as one schema-1 JSON object.
  `MenuItem`, `MenuKind`, `Docs`, `TrayHostSettings`, write_document;
  Registry::document/additions and Presence::start_document/update_document.
  Existing Presence updates preserve the extension cache.
- `app`: `Description {actions, methods}`/supports, `ShortcutVia`,
  `ShortcutSetResult`, `ImportResult`. Handler::methods is opt-in with default
  unsupported callbacks for settings/restart/menu/menu_invoke/shortcuts_set/
  settings_export/settings_import; restart_ready validates before acknowledgment.
  Client has every corresponding typed helper, describe_full, set_timeout and
  connection_control. LinkError::is_unsupported recognizes both the new wire
  error and v0.2's legacy unknown-method internal response. Server sends menu
  change notifications and exposes notify_menu_changed.
- `install` feature: `Environment::under`/discover, `Runtime`, `AppInfo`,
  `Detection`, `State`, `Icon`/`IconSize`, `InstallOptions`, `UninstallOptions`,
  `detect`, is_dev_build, should_prompt, Linux install/repair, receipt-driven
  uninstall, read-only integration_status/path_hint, reexec. Explicit paths,
  caller-owned dialogs/launch policy/data folders, preserved previous AppImage,
  rollback on integration failure, autostart repair without unsolicited creation.
  Native Windows PATH/shim and macOS translocation/bundle/Applications/CLI helpers
  live in install::platform. The macOS ditto helper copies the bundle while
  preserving attributes/quarantine and leaves source cleanup to the app.
  install::strings exposes the included JSON through typed get/format accessors.
- `trayhost` feature: `WatcherConfig`, `TrayState`, `HostState`,
  `TrayHostWatcher::start`/state/set_link_enabled/stop; worker callbacks, never
  UI-thread blocking. `TrayHostServer` attaches to Server, owns subscribers,
  set_hosted/set_excluded/announce_restarting/shutdown. Blocked socket/event reads
  and OS registry watches; only startup 300 ms and restart 5 s hosting deadlines.

## Intended Qt shape (separate task)

Mirror value types and JSON field names 1:1: ArcadeAccelerator's normalize,
platform display and conflicts; ArcadeShortcuts Document/Sheet/effective/
validate/markdown; ArcadeReceipt/ReceiptStore; ArcadeInstall Environment,
Runtime, Detection/State, Options and explicit-path operations. Keep current
ArcadeLink structures/methods intact and add a ManifestDocument extension
wrapper plus optional handler/client methods and unsupported detection.
ArcadeTrayHost owns the same watcher state machine, a background socket and
registry watch; queued stateChanged signals marshal onto the toolkit thread.
A TrayHostServer counterpart tracks peer IDs and mirrors exclusions, restart
announcement and clean shutdown. Do not add the port in this phase.

## Decisions and limits

- Preserve struct-literal and exhaustive-enum compatibility through extension
  wrappers and a custom LinkError wire mapping rather than changing existing
  required fields or adding an ErrorCode variant. Keep legacy registry
  normalization behavior; new consumers use accelerator::normalize/conflicts.
- The pinned format's order rule says Ctrl, Alt, Shift, Super, but its example
  writes Super+Shift+P. Canonical files follow the explicit order (Shift+Super+P);
  lenient normalization accepts either spelling. No modmask helper was added;
  SPEC records the exact supplied Hyprland mask bits.
- Source removal happens only after successful Linux installation. Updates use
  copy/staging and renames for previous/rollback. This is not a power-loss
  transaction across multiple paths; rollback restoration is best effort if
  the filesystem itself continues failing. Repair cannot recreate missing
  icon bytes from receipt metadata, so apps may reinstall bundled icons.
- Keep desktop and autostart identities caller-supplied, including Wheel's
  different autostart ID and Clipboard's dev.arcade.clipboard desktop ID.
  Apps own version comparison, dismissal storage, Tools update ownership UI,
  settings safety, live registration and successor-process waiting.
- Windows named-pipe deadlines cannot use interprocess's unsupported timeout
  setters. Native overlapped I/O waits on completion/cancellation events;
  completion is drained before releasing buffers, including timeout races.
  Reviewed against cached bindings and Microsoft's
  [overlapped I/O](https://learn.microsoft.com/en-us/windows/win32/sync/synchronization-and-overlapped-input-and-output)
  and [CancelIoEx](https://learn.microsoft.com/en-us/windows/win32/api/ioapiset/nf-ioapiset-cancelioex)
  contracts. This review is not a native execution claim.
- Windows installer includes share a vendored PowerShell 5.1 helper to keep
  JSON escaping, PATH preservation, ACLs and atomic writes identical between
  Inno and NSIS. ARCADE_HOME uses an isolated HKCU key, not the real user Path.
- Platform-specific helpers have native gated tests and CI, but Windows/macOS,
  installer execution and MSRV 1.88 have not run here. Only system Rust 1.99 is
  available; no rustup/system packages were installed. New Windows installer
  CI requires GitHub execution and has not been triggered/pushed.
- Tests used temp roots/scoped child environments. No real profile, shell,
  autostart, icon, application or Hyprland configuration was changed, no
  hyprctl dispatch ran, and only test-started children were stopped.
- Qt port, app adoption, new ecosystem e2e groups, benchmarks, glyphs and
  NEW_APP_SPEC are intentionally outside this task. Tray tests are synthetic
  IPC/process tests, not a desktop or whole-app idle/RSS benchmark.
