## Public API and compatibility

Protocol and manifest schema remain 1, Rust edition 2021, MSRV 1.88.
Default features are empty. `install`, `watch` and `engines` work alone;
`trayhost` includes `watch`. Existing public struct literals, enum matches,
Handler implementations and client helpers remain valid. Find and Tools
compile unchanged against the patched crate in temporary source copies.

| Rust surface | Main API |
|---|---|
| `accelerator` | `normalize`, `is_canonical`, `display(Platform)`, `conflicts`; canonical sequences, modifier taps, XKB/keypad/Hyprland aliases, MicMute and horizontal wheel keys |
| `shortcuts` | `Document`, `Sheet`, `Group`, `Shortcut`, validation/effective OS bindings/Markdown/case-insensitive matching; optional manifest rebindable-ID checks |
| `receipt` | `Receipt`, `Integration`, `Previous`, `InstallMethod`, `ManagedBy`, `Store::new/discover/read/write/remove`; portable parsing and separate native mutation preflight |

Tools should use `Server::start_with_tray_host` before publishing an enabled
manifest; this attaches hosting before accepting subscribers. Existing attach
remains available. A failed subscription retries on registry/manifest changes,
including an identical rewrite; idle has no polling. Rust watcher callbacks
run on a background thread. Client/installer operations belong on workers.
Only startup (300 ms) and restart (5 s) hosting deadlines use timers.

## Qt shape and vendoring

`ArcadeTrayHost` mirrors the Rust watcher/state transitions, including GUI-thread
queued startup/state signals, crash hand-back, grace deadlines, exclusions,
Link-off and status.tray. Its worker owns registry/socket work; stop is asynchronous.
`TrayHostStateMachine` exposes deterministic deadline behavior for the vectors.
No Qt Tools-side host is required in this release.

`ArcadeInstall::{Environment,Runtime,Detection,AppInfo,InstallOptions}` and
`ReceiptStore` mirror the Rust operations and JSON field names. Qt uses
QJsonObject for receipts/method payloads instead of adding a parallel public
set of required structs. Portable validation and native path preflight are
separate. Receipts use QSaveFile, Unix 0600, and private Windows user/SYSTEM ACLs.
Linux install/update/rollback/repair/uninstall, Windows shim/PATH helpers and
macOS move helpers are covered. Generic Qt install/repair report an explicit
platform result outside Linux; native Windows installers/macOS helpers handle
those integrations. The Rust AppImage example is cfg-gated on non-Linux.

`Accelerator::{normalize,isCanonical,display,conflicts}` and
`Shortcuts::{validate,effective,markdown,sheetMatches}` run the same vectors.
Server callback opt-in and matching Client helpers cover all seven methods,
describe.methods, app.status tray state and menu-change notifications. Qt
server callbacks run on the owning thread, normally the GUI thread; dispatch
long work to workers. Client calls are blocking worker-thread operations.
Manifest JSON retains additions and unknown fields.

`tools/vendor_qt.py` reads a full Git commit, copies the complete Qt/vector/
fixture/schema/string bundle, records SHA256 values in VENDORED.json, and
checks content against the pin. It refuses overwriting unowned vendor files.
Wheel's old two-source mapping and Shelf's provenance list must expand when
adopting this bundle. No sibling vendor checkout was changed.

Further CI fixes: CLI waits use 10 s for readiness without weakening the
separate <1 s hand-back assertion; PowerShell success exits explicitly and
isolated roots are normalized. Qt socket callbacks detach before server state
destruction (`destroyingServerWithALiveJobDisconnectsSafely`). The CLI preserves
Rust's default SIGPIPE handling during subscription cancellation, and handles
stdout broken-pipe exit quietly. Qt's live restart test synchronizes actual
successor subscribers; shared-clock vectors still assert exact 300/5000 ms
boundaries. Python imports no longer require POSIX SIGKILL. Qt test logs are
retained as files and printed on CI failure.

The Windows Qt shim regression identified a missing-value RegQueryValueExW
call clearing its type output: first Path was REG_NONE and repeat install
failed. Restore REG_EXPAND_SZ on ERROR_FILE_NOT_FOUND and assert its native
type/repeated writes/last-shim cleanup in `nativeShimsUseAnIsolatedRegistryKey`.
`macos_bundle_prompt_uses_the_same_suppression_rules` and Qt's native bundle
test ensure the first-run prompt policy covers .app bundles as well as AppImages.

## Decisions and limits

- Preserve old structs/enums via extension wrappers and wire-error mapping.
  Canonical modifier order is Ctrl, Alt, Shift, Super; the pinned contradictory
  Super+Shift+P example normalizes to Shift+Super+P. No modmask helper was added;
  SPEC records the supplied Hyprland mask bits.
- Only adopt validated legacy integration; preserve/report foreign entries.
  Mutation preflight is stricter than portable receipt parsing. Previous
  backups are owned only through receipts. Updates use staging/copies and
  renames; source deletion happens after success. Ordinary I/O rollback is
  covered, but this is not power-loss atomicity across multiple paths.
- Windows/macOS use native helpers/installer-specific flows, not the Linux
  AppImage harness. macOS ditto retains attributes/quarantine; the caller owns
  source cleanup and user decisions. No shell profile or quarantine removal.
- Apps own version comparisons, dismissal, Tools ownership UI, portable-settings
  safety/backups, shortcut registration/persistence and restart successor waits.
  Same-user IPC authentication does not establish app identity.
- Repair cannot regenerate absent icon bytes from receipt metadata. Cache
  refresh is non-fatal. Native CI does not certify signing/notarization,
  Gatekeeper, real tray painting, Wayland GUI or production Tools performance.
- One Tesseract network-download test stays ignored. Two optional Python
  jsonschema tests skip because the package is absent; stdlib semantic/schema
  regex tests and shared vectors run. No rustup/system packages were installed.
- Current main sibling checkouts do not contain new shortcut docs; the optional
  scan reports missing files. The owner's earlier 7-doc/31-sheet parity run is
  separate evidence. App adoption/full tools-hub e2e and production performance
  remain later phases. Merge/tag are left to the owner.
